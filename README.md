# 瑜伽師地論 · DILA 校勘注記

> 瑜伽師地論（Yogācārabhūmi-śāstra）大藏經文數位化校勘與交叉注記項目

本倉庫收錄《瑜伽師地論》全部一百卷，並整合大正藏、磧砂藏、中華藏等多版本對照，以及大量相關阿毘達磨、菩薩地、攝大乘論等輔翼文獻，以 Markdown 格式組織，支援維基鏈接（Wikilink）交叉參照。

---

## 項目發起因緣

本項目的誕生，源於對 DILA（法鼓數位圖書館）長期累積之大藏經數位化成果的延續與拓展。以下為本項目發起的主要背景：

### 舊體系（2008–2021）

法鼓數位圖書館的網站核心是一組靜態 HTML + Flash 插件，數據以 XML 形式封閉在後端（參見 [YBh XML 標記手冊](https://wiki.dila.edu.tw/pages/YBh_XML_%E6%A8%99%E8%A8%98%E6%89%8B%E5%86%8A)）。系統僅提供只讀 API，無法一鍵鏡像或私有部署。法鼓佛教學院 2008 版 YBh 網站界面可參閱：http://buddhistinformatics.dila.edu.tw/ybh2008/ui.html

### 2022 年重構

法鼓文理學院將代碼庫遷移至 Ruby on Rails 7，前端仍由 XML 驅動，並在 GitHub 開源了部分解析腳本（重構後首頁：https://ybh.dila.edu.tw/）。但由於學術版權與「不鼓勵直接 fork」條款，外部團隊若要在本地運行，仍需人工補全缺失的 XML 文件與授權密鑰，形成事實上的技術壁壘。

### 平行文本對齊

法鼓方面已完成了梵語與藏語的平行文本對齊工作。本項目在此基礎上，進一步整合多語對照資源。

### 福嚴佛學院文獻處理

福嚴佛學院的文獻全部為 Word 文檔，需先轉換為 Markdown 格式並進行數據清洗。此部分主要依據印順導師加注的《阿含經》進行整理。

### 未來規劃

## 文件命名規範

每個文獻系列採用統一命名格式：

- **正文卷冊**：{藏經標識}-{卷號}.md，例如 PXJ-H-1.md、T1579-50.md
- **索引/目錄**：{藏經標識}-k.md，例如 PXJ-H-k.md、T1579-k.md
- **補遺/附錄**：{藏經標識}-a.md（部分系列有）

## 交叉參照系統

本文獻採用 Obsidian 風格的維基鏈接語法，實現文獻間的即時跳轉：

    [[T1580-1#^kpD05-005|論釋]]
    [[PXJ-H-85#^kpD11-2064|披尋記]]
    [[CT3267-1#^kpD04-034|CT3267]]

格式說明：

- [[文件名#錨點|顯示標籤]] — 鏈接至指定文件的指定錨點（段落標記）
- 錨點格式：^kpD01-001 等，對應科句披尋記的段落編號系統
- 支持跨版本鏈接：如 T1579 文可鏈接至 PXJ-H 對應段落，反之亦然

## 技術架構

- **格式**：純 Markdown（.md），便於版本控制與文獻檢索
- **導航**： _sidebar.md 提供完整目錄樹
- **首頁**： index.html 提供 Web 瀏覽器訪問（基於 Docsify）
- **防攔截**： .nojekyll 禁用 Jekyll 處理（GitHub Pages 兼容）
